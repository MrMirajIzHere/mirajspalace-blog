i found an undocumented "help" menu by putting a serial bowl ontop of the v8
and turning it on

some of the options are documented, so i won't expand on them much


V-8 Help key combo my description
Init [MIX]+[BPM]+[TRSF-B] is documented and resets the mixer
Version [InpA4]+[InpB1] displays the firmware version
MakeTime [InpA8]+[InpB5] displays either the date/time firmware was compiled, or the mixer was made.
same date/time is also displayed on the display as a marquee,
when time is displayed leds on "output fade", "tap bpm", and "output preview" cycle in circular pattern.
Preset [FXA1]+[FXA4] resets the device to factory, displaying FAC on the display
NTSC/PAL [PRV-1]+[PRV-0] changes the default color system
Test Mode [MENU]+[ENTER] is documented in the service notes, displays TST on the display
Set Mode [UP]+[DOWN] is expansion of Test Mode with actual calibration options, displays SET on the display,
the mixer is almost fully operational in this mode
MIDIup [M1]+[MIX]+[<]+[>] is likely firmware updater via MIDI,
but "<" and ">" buttons remain a mystery to me
(didn't try since there is a case of someone bricking their mixer)
Romup [M8]+[EFX]+[<]+[>] is likely a ROM updater(also didn't try for the fear of bricking the mixer)
V-8Help [TAP] starts the mixer into this mode, displays HLP on the display(no space between v-8 and help is kinda funny)
